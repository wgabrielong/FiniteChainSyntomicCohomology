# p-adic K-theory of O_K/ϖ², K = Q₃[x]/(x³ + 6x² + 21)

[All rings](../README.md) · the same data: [`k_theory.json`](../data/k_theory.json), [`k_theory.csv`](../data/k_theory.csv)

The p-adic K-groups K_r(R; Z₃) for 1 ≤ r ≤ 100. As in [AKN, Appendix A], each entry lists the exponents a₁ ≤ a₂ ≤ … of the decomposition K_r(R; Z₃) ≅ Z/3^a₁ ⊕ Z/3^a₂ ⊕ …, and `0` is the zero group (a blank cell in [AKN]). K_0(R; Z₃) = Z₃.

K = Q₃[x]/(x³ + 6x² + 21) is ramified over Q₃, with e = 3 and discriminant exponent 4 (LMFDB [3.1.3.4a2.3](https://www.lmfdb.org/padicField/3.1.3.4a2.3)). R = O_K/ϖ² = Z₃[z]/(E(z), z²) with E(z) = z³ + 6z² + 21, the defining polynomial of the LMFDB, and ϖ a root of E. |R| = 3².

Since n ≤ e, R = F₃[z]/z². Hesselholt and Madsen computed the K-groups of these rings (cited in [AKN, §1.1, p. 2]): K_{2i−1}(F_q[z]/zⁿ; Z_p) ≅ W_{ni}(F_q)/V_n W_i(F_q) and K_{2i−2}(F_q[z]/zⁿ; Z_p) = 0 for i ≥ 2. Every group below agrees with their formula, so none is new.

O_K/ϖ² is the same ring for K = [Q₃(√−3)](Q3_sqrt-3_n2.md), [Q₃(√3)](Q3_sqrt3_n2.md), [Q₃(∛2)](Q3_cbrt2_n2.md), [Q₃[x]/(x³ + 6x + 3)](Q3_3.1.3.3a1.2_n2.md), [Q₃[x]/(x³ + 3x² + 3)](Q3_3.1.3.4a1.1_n2.md), [Q₃(ζ₉)⁺](Q3_zeta9plus_n2.md), [Q₃[x]/(x³ + 6x² + 12)](Q3_3.1.3.4a2.2_n2.md), [Q₃(∛3)](Q3_cbrt3_n2.md), [Q₃(∛12)](Q3_cbrt12_n2.md), [Q₃(∛6)](Q3_cbrt6_n2.md) (see the [coincidences](../docs/coincidences.md#across-the-families)), so those tables equal this one.
