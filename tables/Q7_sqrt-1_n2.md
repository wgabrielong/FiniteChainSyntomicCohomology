# p-adic K-theory of O_K/ϖ², K = Q₇(√−1)

[All rings](../README.md) · the same data: [`k_theory.json`](../data/k_theory.json), [`k_theory.csv`](../data/k_theory.csv)

The p-adic K-groups K_r(R; Z₇) for 1 ≤ r ≤ 100. As in [AKN, Appendix A], each entry lists the exponents a₁ ≤ a₂ ≤ … of the decomposition K_r(R; Z₇) ≅ Z/7^a₁ ⊕ Z/7^a₂ ⊕ …, and `0` is the zero group (a blank cell in [AKN]). K_0(R; Z₇) = Z₇.

K = Q₇(√−1) is the unramified quadratic extension of Q₇ (LMFDB [7.2.1.0a1.1](https://www.lmfdb.org/padicField/7.2.1.0a1.1)), so ϖ = 7 and R = O_K/7² = W₂(F₄₉), where W(F₄₉) = Z₇[x]/(x² + 6x + 3). |R| = 49².

[AKN] tabulate no ring of this kind, so all 100 groups are new relative to their tables. They are in **bold**.
