# p-adic K-theory of O_K/ϖ⁴, K = Q₃[x]/(x³ + 6x + 3)

[All rings](../README.md) · the same data: [`k_theory.json`](../data/k_theory.json), [`k_theory.csv`](../data/k_theory.csv)

The p-adic K-groups K_r(R; Z₃) for 1 ≤ r ≤ 100. As in [AKN, Appendix A], each entry lists the exponents a₁ ≤ a₂ ≤ … of the decomposition K_r(R; Z₃) ≅ Z/3^a₁ ⊕ Z/3^a₂ ⊕ …, and `0` is the zero group (a blank cell in [AKN]). K_0(R; Z₃) = Z₃.

K = Q₃[x]/(x³ + 6x + 3) is ramified over Q₃, with e = 3 and discriminant exponent 3 (LMFDB [3.1.3.3a1.2](https://www.lmfdb.org/padicField/3.1.3.3a1.2)). R = O_K/ϖ⁴ = Z₃[z]/(E(z), z⁴) with E(z) = z³ + 6z + 3, the defining polynomial of the LMFDB, and ϖ a root of E. |R| = 3⁴.

O_K/ϖ⁴ is the same ring for K = [Q₃(∛2)](Q3_cbrt2_n4.md), [Q₃[x]/(x³ + 3x² + 3)](Q3_3.1.3.4a1.1_n4.md), [Q₃(ζ₉)⁺](Q3_zeta9plus_n4.md), [Q₃[x]/(x³ + 6x² + 12)](Q3_3.1.3.4a2.2_n4.md), [Q₃[x]/(x³ + 6x² + 21)](Q3_3.1.3.4a2.3_n4.md), [Q₃(∛3)](Q3_cbrt3_n4.md), [Q₃(∛12)](Q3_cbrt12_n4.md), [Q₃(∛6)](Q3_cbrt6_n4.md) (see the [coincidences](../docs/coincidences.md#among-the-cubic-rings)), so those tables equal this one.
