# FiniteChainSyntomicCohomology

Tables of the p-adic K-groups K_r(Z/p^n; Z_p), 1 ≤ r ≤ 100, of the 19 rings Z/p^n tabulated
in Appendix A of

> [AKN] B. Antieau, A. Krause and T. Nikolaus, *On the K-theory of Z/p^n*,
> [arXiv:2405.04329](https://arxiv.org/abs/2405.04329),

computed with [Syntomic.jl](https://github.com/wgabrielong/Syntomic.jl), an implementation of the
algorithm of [AKN, §7.1, pp. 53–57].

Of the 1,900 groups, [AKN] print 799. Syntomic.jl gives the same result for every one of them.
[AKN] mark 494 more with x (not computed within 48 hours), and the remaining 607 lie beyond the
last degree of their tables. So **1,101 groups are new**. They are in **bold** in the tables.

## Tables

There is one page per ring. Each page lists K_1 to K_100 as [AKN, Appendix A] do, and marks
every group as *printed* in [AKN], *x* in [AKN] or *beyond* their table.

The column *new here* counts the groups marked x in [AKN] and those beyond their table. *Time*
is the wall-clock time for all 51 weights of the ring (see

peak resident memory of that run.

## Reading the tables

- An entry `a₁,a₂,…,a_k` (with a₁ ≤ a₂ ≤ … ≤ a_k) means
  K_r(Z/p^n; Z_p) ≅ Z/p^a₁ ⊕ Z/p^a₂ ⊕ … ⊕ Z/p^a_k. This is the notation of
  [AKN, Appendix A, p. 61]. For example, the entry `1,1,6` of K_15(Z/3²; Z₃) means
  Z/3 ⊕ Z/3 ⊕ Z/3⁶.
- `0` is the zero group, which [AKN] leave blank. The column *order* gives
  |K_r| = p^(a₁ + … + a_k).
- K_{2i−1}(Z/p^n; Z_p) ≅ H¹(Z_p(i)(Z/p^n)) for i ≥ 1 and K_{2i−2}(Z/p^n; Z_p) ≅ H²(Z_p(i)(Z/p^n))
  for i ≥ 2 [AKN, §1.1, p. 3; Cor. 2.16, p. 9]. So K_1 to K_100 come from the weights 1 ≤ i ≤ 51.
  K_0(Z/p^n; Z_p) ≅ Z_p is not listed.
- **Integral K-groups.** The prime-to-p part of K_r(Z/p^n) is that of K_r(F_p)
  [AKN, §1.1, p. 2]. So K_{2i−1}(Z/p^n) ≅ K_{2i−1}(Z/p^n; Z_p) ⊕ Z/(p^i − 1), and
  K_r(Z/p^n) ≅ K_r(Z/p^n; Z_p) for even r ≥ 2.

## Files

| file | contents |
|:--|:--|
| [`tables/zpn_<p>_<n>.md`](tables) | the table of one ring, as above |
| [`data/k_theory.json`](data/k_theory.json) | all 1,900 groups with their status in [AKN], and the computation of each ring |
| [`data/k_theory.csv`](data/k_theory.csv) | the same groups, one row per ring and degree |
| [`data/cohomology/zpn_<p>_<n>.json`](data/cohomology) | H¹ and H² of Z_p(i)(Z/p^n) for 1 ≤ i ≤ 51, with the working precision of each weight, as written by Syntomic.jl's `save_results` (format `syntomic-results-v1`) |
| [`data/runs/zpn_<p>_<n>.json`](data/runs) | the software versions, the Syntomic.jl commit, the machine, the time and the peak memory of each ring's run |
| [`data/akn_appendix_A.json`](data/akn_appendix_A.json) | a transcription of [AKN, Appendix A, pp. 61–64]: the printed groups and the degrees marked x |

**`k_theory.json`** has the fields `format` (`"finite-chain-k-theory-v1"`), `akn`,
`conventions` and `rings`. Each ring has these fields:

- `ring`, `p`, `n`, `lmfdb_label`: the label of Q_p used by [AKN];
- `akn_section`, `akn_page`, `akn_max_degree`: where [AKN] tabulate the ring, and the last
  degree of their table;
- `computation`: the contents of `data/runs`;
- `groups`: one entry per degree.

```json
{"r": 25, "exponents": [1,1,1,2,2,3,4,12], "akn": "x", "new": true}
```

`exponents` is the sorted list of the a_j, with `[]` for the zero group. `akn` is `"printed"`,
`"x"` or `"beyond"`. `new` is true unless `akn` is `"printed"`.

**`k_theory.csv`** has the columns `ring,p,n,r,exponents,order_exponent,akn,new`. In
`exponents` the a_j are separated by `;`, and the field is empty for the zero group.
`order_exponent` is a₁ + … + a_k.

## How the groups were computed and checked

- **Computation.** For each ring, Syntomic.jl computes the syntomic complexes Z_p(i)(Z/p^n) of
  [AKN, Thm. 1.1, p. 3] for 1 ≤ i ≤ 51. It uses the algorithm of [AKN, §7.1, pp. 53–57] and
  takes the cohomology from the Smith normal forms of the two differentials. Each ring is one
  sweep over its weights, `syntomic_sweep(zpn(p, n), [n], 1:51)`, run in a fresh Julia process
  ([`scripts/compute.jl`](scripts/compute.jl)).
- **Certification.** The cohomology is correct once both differentials are known modulo p^M,
  have full rank modulo p^M and have no elementary divisor of valuation M or more
  [AKN, Lemma 7.1, p. 57; Remark 7.3, p. 58]. Syntomic.jl checks this for every weight, and raises
  an error rather than return an answer it cannot certify. The working precision of each weight
  is recorded in `data/cohomology`.
- **Checks.** [`scripts/build.jl`](scripts/build.jl) writes the tables. It stops with an error
  unless both of these hold:
  - every group printed in [AKN, Appendix A] equals the computed one (799 groups);
  - Angeltveit's quotient |H¹(Z_p(i))| / |H²(Z_p(i))| = p^(i(n−1)) [AKN, Prop. 2.18, p. 9] holds
    for all 19 × 51 weights.

  The workflow [`check`](.github/workflows/check.yml) reruns `build.jl --check` on every push.
  It fails if either check fails, or if a table no longer matches the data.

## Reproducing

```sh
# the computation of one ring (here Z/7^7); needs read access to Syntomic.jl, which the git
# command line (JULIA_PKG_USE_CLI_GIT=true) has with the usual GitHub credentials
JULIA_PKG_USE_CLI_GIT=true julia --project=scripts/compute -e 'using Pkg; Pkg.instantiate()'
julia --project=scripts/compute -t 8 scripts/compute.jl 7 7

# the tables, the JSON and CSV files, and the table of rings above
julia --project=scripts -e 'using Pkg; Pkg.instantiate()'
julia --project=scripts scripts/build.jl
```

`scripts/compute/Project.toml` pins the Syntomic.jl commit that computed the data. Z/7⁷, the
largest ring, takes 10 minutes and 27 GiB of memory on 8 threads; the other rings take less
(see the [table of rings](#tables)).
